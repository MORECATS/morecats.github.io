# Website assets

- `app-icon.png`: copied from `BingDaily/Assets.xcassets/AppIcon.appiconset/Bing1024.png`.
- `default-wallpaper.jpg` and `default-wallpaper.json`: Bing's 2026-11-14 Victoria Harbour photo (1920 × 1080), with matching English and Chinese captions and source URLs. The initial photo, credit, and metadata are embedded in `index.html` so the default works without JavaScript or network access. Traditional Chinese is converted ahead of time. Today’s wallpaper replaces it only after a successful background load.
- `app-store-{en-us,zh-cn,zh-tw}.svg`: unmodified localized black download badges from [Apple Marketing Tools](https://toolbox.marketingtools.apple.com/api/v2/badges/download-on-the-app-store/black/zh-cn), downloaded on 2026-11-15. Follow the [App Store Marketing Guidelines](https://developer.apple.com/app-store/marketing/guidelines/) when using the badges.
- `fonts/RobotoFlex-latin-opsz-wdth-wght.woff2`: Roboto Flex 3.200, Latin subset supplied by [Google Fonts](https://fonts.google.com/specimen/Roboto+Flex). Its variable axes are optical size (8–144), weight (100–1000), and width (25–151). Distributed under the included `fonts/OFL.txt`. Chinese glyphs use system font fallbacks.
- `vendor/opencc-cn2t-1.4.2.js`: the unmodified `dist/umd/cn2t.js` browser bundle from the [opencc-js 1.4.2 release](https://www.npmjs.com/package/opencc-js/v/1.4.2), loaded only for Traditional Chinese photo captions. The license, Apache 2.0 text, and third-party notices are included alongside it.

The language picker uses the URL's `lang` parameter first (`en`, `zh-Hans`, or `zh-Hant`), then a saved choice, then the browser language. Clicking a button updates the URL without reloading and remembers the choice when storage is available. English uses Bing's US market, Los Angeles time, and `start_date`; Chinese uses the China market and `end_date` in Shanghai/Taipei time. Traditional Chinese captions are converted from the Simplified Chinese source with OpenCC, because Bing's Taiwan/Hong Kong endpoints return English. Cached source metadata is shared between Chinese variants; US data has its own cache. Failed updates retain the default or last successful photo and retry silently after 15 minutes.
